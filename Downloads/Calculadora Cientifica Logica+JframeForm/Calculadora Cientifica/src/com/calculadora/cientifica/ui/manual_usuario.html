Manual de Usuario — Calculadora Científica

Proyecto universitario de cálculo simbólico y numérico.

💡 Consejo: puedes alternar entre editor y vista previa con F4.

Operaciones soportadas

  • Cálculo básico: +, −, *, /, potencias ^, raíces √( ), constantes π, e.
  • Trigonometría: sin, cos, tan.
  • Logaritmos: log10, ln, exp, abs.
  • Derivadas: botón Derivar o CtrlD, luego presiona =.
  • Integral indefinida: botón Integral indef. o CtrlI, luego =.
  • Integral definida: llena a y b y pulsa ∫ a→b o Enter en los campos.

Selector de variable

Elige x o y desde el menú desplegable Variable según la variable de integración o derivación.

Atajos útiles

  • Enter — calcular.
  • Esc o botón CLR — limpiar pantalla.
  • F4 — alternar entre editor y vista previa.
  • Ctrl + D — modo derivada.
  • Ctrl + I — modo integral indefinida.

Ejemplos rápidos

  • sin(x)^2 + cos(x)^2 → 1
  • d/dx (ln(x^2 + 1)) → 2x / (x² + 1)
  • ∫ x^2 dx → x³/3 + C
  • ∫[0,1] (3x^2) dx → 1

Historial

El botón Historial permite consultar los cálculos previos. Puedes hacer clic en cualquier línea para volver a cargar esa expresión en la pantalla principal.

Notas adicionales

  • La calculadora usa el motor simbólico Symja y Apache Commons Math para cálculos numéricos precisos.
  • El diseño está basado en Swing (JFrame Form) y se programó con arquitectura orientada a objetos.
